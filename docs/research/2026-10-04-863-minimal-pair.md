# #863: Measuring 最小對照 on a synthetic pair set (Claude Code approximation)

**Ticket:** [#863](https://github.com/paulpengtw/exam-generation/issues/863). **Parent:** [#860](https://github.com/paulpengtw/exam-generation/issues/860).
**Corpus:** `origin/staging@946fb32`, the same corpus as #861 and #862.
**Assets:** [`863-minimal-pair/`](863-minimal-pair/). The script is [`scripts/research/rubric_863_minimal_pair.py`](../../scripts/research/rubric_863_minimal_pair.py).

## Summary

The 最小對照 rule from [#653](https://github.com/paulpengtw/exam-generation/issues/653) was measured on a synthetic set: 19 open-response items, 105 [2]/[1] pairs. Positive means a violation, so the checker should flag it.

| Near-miss type | n | Checker right | Rate |
|---|---|---|---|
| `true_pair` (pass) | 19 | 18 | **1 false flag** (5%) |
| `framed_omission` (pass) | 9 | 9 | 0 false flags |
| `different_claim` | 19 | 19 | 100% recall |
| `no_reason` | 19 | 18 | 95% recall |
| `closes_chain` (a mislabelled [2]) | 19 | 17 | 89% recall |
| `fewer_points` (not framed) | 10 | 6 | **60% recall** |
| `omission_plus_gap` (framed) | 9 | 0 | **0% recall** |
| `omits_two` (framed) | 1 | 1 | 100% recall |
| **All** | 105 | 88 | recall 79% (61/77), false flags 4% (1/28) |

Three findings matter more than the totals:

- **The obvious shapes are caught.** A different claim, a missing reason, or a [1] that is really a [2] are flagged in 54 of 57 cases.
- **The omission exception is read as a blanket pass.** On a framed item, a [1] that leaves out one member is passed even when the member it keeps has a broken reason: 0 of 9 caught. The checker sees the omission and stops looking.
- **The checker calls almost every item framed.** `set_framed` was true on **41 of 50** units the labeller marked not framed, and on all 55 framed units. That is what lets `fewer_points` through: all 4 misses are on units the checker called framed. Its stated bases are a reasoning chain fixed by the concept, a stem that asks for data to be cited, or a stem with one correct choice. That is the failure mode [#872](https://github.com/paulpengtw/exam-generation/issues/872) named for the counting criterion's misses, so it is a question about 【判準】 itself, not only about this flag (see "For the owner" below).

**Recommendation: note only for now**, with two criterion amendments, then a real-harness re-run. The framing question goes to the owner first, because the fix depends on what 【判準】 is meant to frame.

## Method

The owner chose this method for #861 and #862, and this ticket follows it: a **Claude Code approximation, without an API key**.

**The extension to the criterion.**
- **System prompt.** The block's 最小對照 bullet is added verbatim to the 【學生作答實例】 clause. 「最小對照」 is dropped from the out-of-scope note.
- **User prompt.** The output gains `minimal_pair_violation` and `minimal_pair_reason`. Findings are reported on the `example_details` line, as #862 recommended. The example header notes that examples at one level are listed in order, so "the first [1]" is defined.

**The synthetic set** ([`synthetic_set.json`](863-minimal-pair/synthetic_set.json)).
- **19 items in three strata:**
  - 10 not framed;
  - 7 framed by the stem;
  - 2 framed by a figure or table under [#859](https://github.com/paulpengtw/exam-generation/issues/859).
  
  Both 社會領域 `範例_` rows are included.
- **Each item has a conforming 0 / 1 / 2 rubric.** Its [1] 規準說明 names the two gaps that the two [1] examples show. A 1 / 2 / 1 example set is held fixed per item, and only the first [1] example changes from variant to variant.
- **The real pair is kept verbatim.** `fasting-method` 序號 2's [2] and [1] examples, #653's one clean real pair, are its `true_pair`.
- **#859's relabels.** `entomopathogenic-fungi` 6 is used as a stem-framed item. No other relabelled entry is reused.
- **Pure "why" 小題 are not used** (`candle-burning` 3, `homemade-fruit-jelly` 7). In a 小題 that asks only 「為何…」, the claim is the explanation, so "same claim, broken reason" has nothing to grip. This is noted as a limit of the rule, not measured.

**The figure is never shown.** The corpus has no image files for these items, as in #651. Figure-framed units are reported as their own stratum.

### A label leak in the first checker run, and the re-run

The first checker run gave each subagent the batch files as committed in `34c8c10`. Each line's `unit_key` ends in the design type (`…|closes_chain`, `…|true_pair`), so the expected answer was visible. One subagent's summary named units by those suffixes. **All of that run was discarded:** two batches were stopped, and the five finished batches were set aside unused.

The run reported here used copies of the same 105 prompts under opaque ids (`q000`…), with the id map held apart. The prompt text never contained a variant name. The committed `batches/` files now carry opaque ids too, with the map in [`batch_id_map.json`](863-minimal-pair/batch_id_map.json).

## For the owner: a question about 【判準】

The checker's `framing_evidence` shows how it reads 【判準】's 「能框定」. On the 50 not-framed units it called 41 framed, citing:
- **a reasoning chain**: 「推理鏈（改變次數→時間同步改變→變因混淆）由科學概念本身決定，集合可事前框定」;
- **a stem that asks for data to be cited**: 「題目要求『依據數值說明』，圖1與圖2的數據固定了完整答案中需引用的成分」;
- **a stem with a fixed choice**: 「題幹固定『小丁vs小基』選項…為唯一完整答案集合」.

The block's own example invites the first reading: 「或該科學概念本身即由數個必要環節構成」. Every explanation has necessary links, so on this reading every item is framed. That has two effects:
- the 最小對照 exception covers every omission;
- the counting criterion's 「不能框定 → 不得依數量分級」 almost never fires. #651 measured its recall at 4 of 8, and #872 traced its misses to this same inference.

So this is not a checker-wording fix this ticket can make. It is a question about where 【判準】's framing stops, filed for a decision as its own ticket.

## Recommendation for #860

**最小對照: note only, for now.** It is safe on true pairs (1 false flag in 19, and that one is a reading question), and it reliably catches the obvious shapes. But it misses the counting shape (`fewer_points`) whenever it calls the item framed, which is most items. That shape is the one this map exists to stop. Upgrade it to **fail** after:

1. **The owner rules on the framing question above.** It decides what the exception and the counting check can lean on.
2. **Two amendments to the criterion text** (checker only; the generator block is unchanged unless the owner decides otherwise):
   > 最小對照的理由不必與 [2] 實例相同，只要附了理由、但沒有接上推理鏈即可。
   >
   > 「能框定」時缺少一個具名成分，其餘成分的主張與理由仍須與 [2] 實例一樣完整；缺少成分之外又有理由缺口，屬違反。
3. **A real-harness re-run** of this set, with the amended text and the owner's framing ruling. The cache key includes the prompt hash, so the amended text re-runs everything.

`details` sentence for the corrector:

> [學生作答實例檢核] [1] 的第一個實例不是 [2] 實例的最小對照（<主張不同／多了或少了要點／未附理由／理由其實已完整>）；請改寫成與 [2] 實例主張相同、要點數相同、也附了理由，但理由沒有接上推理鏈（<本題最可能的缺口>）的作答。

**Wiring note.** No rubric-level verdict failed in this run (0 of 105), and #862's three example flags fired on only 3 units. On these conforming rubrics, the 最小對照 line would be the only `example_details` content in most failing calls.

## Limits

- **Approximation.** The checker ran as Claude Code subagents, not through `LLMClient`, so the matrices must be re-confirmed on the real harness.
- **Synthetic, and written by the labeller.** Near-misses are clean by construction. Real generator output will be messier, and the set measures what the checker does with clear cases.
- **Small cells.** `fewer_points` has 10 units and `omission_plus_gap` 9. One flip moves the rate by 10–11 points.
- **No figures.** Figure-framed units were judged without the figure. The checker called both figure items framed from the stem's wording (「哪兩項因素」「由附表」), which 【注意】 says a count alone cannot do.
- **The 【額外項目】 fixed sentence is left out of the rubrics**, because #862's checker prompt has no 【額外項目】 clause. [#874](https://github.com/paulpengtw/exam-generation/issues/874) measures it.
- **Pure "why" 小題 are not covered.** See Method.
